# Linux Commands

Common Linux terminal commands for beginners and IT support.

## Navigation

### `pwd`

Displays the current directory.

```bash
pwd
```
### `ls`

Lists files and directories.

```bash
ls
```
### `cd`

Changes directories.

```bash
cd /home/user
```

## Files & Directories

### `mkdir`

Creates a directory.

```bash
mkdir test
```
